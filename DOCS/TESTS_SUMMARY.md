## 🔧 Вспомогательные функции (`helpers.ts`)

### Основные функции

```typescript
// Регистрация
registerUser(page, email, password)
  ↓ Переход на регистрацию, заполнение, отправка

// Вход
loginUser(page, email, password)
  ↓ Заполнение, отправка

// Верификация
verifyCode(page, code = '123456')
  ↓ Ввод кода, проверка

// Профиль
completeProfile(page)
  ↓ Пропуск шага 1, выбор интересов, завершение

// Полные сценарии
completeFullRegistration(page, email, password)
  ↓ registerUser → verifyCode → completeProfile

completeFullLogin(page, email, password)
  ↓ loginUser → verifyCode → completeProfile

// Выход
logout(page)
  ↓ Клик logout, проверка страницы входа

// Утилиты
generateTestEmail()
  ↓ Уникальный email для тестов
```

## 🔒 Безопасность и данные

### Mock AuthService

Все тесты используют **mock AuthService** с предустановленными данными:

```typescript
// Учётная запись для входа
email: "admin@example.com"
password: "admin123"

// Код верификации
code: "123456"

// Для регистрации
- Любой email (уникальность не проверяется в mock)
- Пароль: минимум 6 символов
```

### Хранение токенов

```typescript
// SessionStorage (имитация HTTPOnly cookies)
sessionStorage.setItem('authToken', token)

// Проверка в тестах
const token = await page.evaluate(() => sessionStorage.getItem('authToken'))
```

## 🆘 Частые проблемы и решения

### ❌ Ошибка: "Element not found"

```bash
# Решение 1: Используйте Debug режим
npm run test:debug

# Решение 2: Проверьте селектор
npx playwright test -g "тест" --headed
```

### ❌ Ошибка: "Timeout"

```bash
# Увеличьте таймаут в тесте
await expect(element).toBeVisible({ timeout: 10000 })
```

### ❌ Тесты работают локально, но падают на CI

```bash
# Решение: Добавьте явное ожидание
await page.waitForLoadState('networkidle')
```

### Шаг 1: Создайте файл

```bash

```

### Шаг 2: Напишите тест

```typescript
import { test, expect } from '@playwright/test';

test.describe('Моя функция', () => {
  test('мой тест', async ({ page }) => {
    await page.goto('/');
    // Ваш код
    await expect(page.locator('...')).toBeVisible();
  });
});
```

```bash
npx playwright test tests/my-feature.spec.ts --headed
```
