## 🚀 Команды для использования

### Основные
```bash
npm run test          # Все тесты на всех браузерах
npm run test:ui       # Интерактивный UI режим
npm run test:headed   # С видимыми окнами браузеров
npm run test:debug    # Debug режим (пошаговый)
```

### По браузерам
```bash
npm run test:chromium # Chrome
npm run test:firefox  # Firefox
npm run test:webkit   # Safari
npm run test:mobile   # iPhone & Android
```

### Утилиты
```bash
npm run test:report   # Показать отчёт
npm run test:nav      # Показать навигацию
```

### Конкретные тесты
```bash
npx playwright test tests/auth-login.spec.ts
npx playwright test -g "успешный вход"
npx playwright test -g "регистрация" --headed
```
